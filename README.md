# Пользовательский обработчик и логгер базы данных для mitmproxy

Этот репозиторий содержит пользовательский обработчик для `mitmproxy`, который логирует HTTP-запросы и ответы, включая модификации на основе определенных условий, таких как блокировка рекламы, трекеров и изменение определенного типа контента. Также включает функциональность для сохранения этих логов в базе данных SQLite.

## Функции

- **Логирование запросов и ответов**: Логирует все HTTP-запросы и ответы, включая заголовки и содержимое тела.
- **Фильтрация контента**: Блокирует распространенные серверы рекламы и трекеры, модифицирует контент с определенных хостов (например, YouTube, Яндекс), обрабатывает сжатые данные (gzip, zstandard, brotli).
- **Хранение в базе данных**: Сохраняет залогированные данные в базе данных SQLite для дальнейшего анализа.
- **Параллельная обработка**: Асинхронно обрабатывает и сохраняет данные в базу данных без прерывания работы прокси-сервера.

## Требования

- Python 3.x
- `mitmproxy`
- `msgpack` для сжатия лога в базу данных.
- Дополнительные библиотеки (`zstandard`, `gzip`, `brotli`) для обработки сжатых данных.

## Установка

1. Установите необходимые пакеты Python:

   ```bash
   pip install mitmproxy zstandard brotli msgpack
   ```

2. Запустите скрипт:

   ```bash
   python main.py
   ```

   Это запустит `mitmproxy` с пользовательским обработчиком и начнет логирование запросов и ответов.

3. Чтобы просмотреть сохраненные логи, выполните SQL-запрос к файлу базы данных `mitm.sql`.

## Настройка

Скрипт включает опцию конфигурации (`SAVE_REQUESTS`), которая позволяет переключаться между сохранением запросов в базу данных. По умолчанию эта опция установлена в `True`.
